# Adaptive protocol dogfood

This is the bounded, read-only Block 11 operator evidence surface. It composes
the maintained inline-correction, bounded-candidate, program-revision,
target-class, and adaptive-decision checkpoints; it is not another decision
engine and conveys no application, release, policy, mission, lifecycle, or
external-effect authority.

Run the frozen matrix from a clean exact revision:

```bash
/usr/bin/python3 implement-tracker-blocks/scripts/adaptive_protocol_dogfood.py --pretty
```

The result contains the raw input condition and observed disposition for each
case, the current effect or protocol root, owner handoff posture, total human
requests, bounded candidate usage and retirement, and the exact maintained
recovery checks. The input fixture intentionally contains no expected or
intended disposition, so an independent reviewer can inspect the evidence
without being told the desired judgment first.

The demonstrated envelope is deliberately small:

- an ordinary target corrects a wrong owner, lower-power path, or unsupported
  generalized layer inside the current Block;
- a justified incumbent returns through the cheap unchanged path;
- implementation comparison opens only when read-only evidence is
  insufficient and closes with one incumbent authority plus a non-authorizing
  handoff or retirement;
- exact structural evidence routes to the existing authoring owner;
- Software Factory self-work uses the same semantic paths while keeping
  application and adoption with the existing normal owners;
- full-autonomous ordinary work remains owner-ready with zero human requests,
  while an unavailable external act is narrowly deferred and safe work remains;
- stale, duplicate, interruption, losing, inconclusive, reopened-outcome, and
  rejected-structure checks reuse the maintained owner regressions.

The matrix creates only temporary repositories and canonical evidence. It does
not edit a target tracker, cut over a candidate, mutate live configuration,
install or release a skill, contact an external service, or claim statistical
superiority. A green matrix is necessary process evidence, not sufficient
current-behavior acceptance; completion still requires exact-revision
independent review of the raw cases and observable roots.
