# Software Factory 2.0 Runtime

This package is the native execution and learning control plane for Software Factory.
It replaces the previous file-ledger control plane with transactional SQL state while
preserving and expanding the full automation, supervision, QA, reflection,
experimentation, signal discovery, program evolution, and self-improvement behavior.

The implementation is in active refactor until the behavioral acceptance matrix in
`docs/acceptance-matrix.md` is fully passing.
